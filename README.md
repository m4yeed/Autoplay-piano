<h1 align="center">Autoplay-piano</h1>

<p align="center">
  Minimal desktop app that plays piano melodies on key press.
</p>

![Autoplay-piano](docs/screenshot.png)

## Features

- One key press = one note from your song, hold to repeat
- Custom hotkeys
- Note timeline with the current note highlighted
- Song library with transcription labels
- Custom CSS field to restyle the UI

## Run

1. Install [Python](https://www.python.org/downloads/) (check **Add Python to PATH**).
2. Download the repo: **Code → Download ZIP**, then unzip.
3. Open a terminal in the folder and run:
   
   pip install -r requirements.txt
   py app.py
   

## How to use

1. Create a song and paste the notes
2. Set your trigger keys in settings
3. Press **Arm**, switch to the game, hit a trigger key
4. Each press plays the next note. Hold to repeat

## Customize

Open settings and put your own CSS into the custom CSS field.

## Возможности

- Одно нажатие = одна нота из песни, при зажатии повторяется
- Свои хоткеи
- Лента с нотами, текущая подсвечивается
- Библиотека песен с пометкой транскрипции
- Поле для своего CSS, чтобы поменять внешний вид

## Запуск

1. Установи [Python](https://www.python.org/downloads/) (поставь галочку **Add Python to PATH**).
2. Скачай репозиторий: **Code → Download ZIP** и распакуй.
3. Открой терминал в папке и выполни:
   
   pip install -r requirements.txt
   py app.py
   

## Как пользоваться

1. Создай песню и вставь ноты
2. Выбери клавиши-триггеры в настройках
3. Нажми **Arm**, перейди в игру и нажми триггер
4. Каждое нажатие играет следующую ноту, при зажатии повторяется

## Кастомизация

Открой настройки и вставь свой CSS в поле кастомного CSS.
