## Download

Get the latest `.exe` from [Releases](../../releases/latest) and run it. No install needed.

## How to use

1. Create a song and paste the notes: `pfiF gjE gKD`
2. Set your trigger keys in settings
3. Press **Arm**, switch to the game, hit a trigger key
4. Each press plays the next note. Hold to repeat

> If Windows shows a warning, click **More info → Run anyway**.

## Скачать

Возьми последний `.exe` в [Releases](../../releases/latest) и запусти. Установка не нужна.

## Как пользоваться

1. Создай песню и вставь ноты: `pfiF gjE gKD`
2. Выбери клавиши-триггеры в настройках
3. Нажми **Arm**, перейди в игру и нажми триггер
4. Каждое нажатие играет следующую ноту, при зажатии повторяется

> Если Windows показывает предупреждение, нажми **Подробнее → Выполнить в любом случае**.
